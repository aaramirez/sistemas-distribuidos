# Sistemas distribuidos

Muchas máquinas que se comportan como una sola: fallas, relojes de Lamport y vectoriales, replicación, consistencia, CAP, consenso con Paxos y Raft, transacciones distribuidas y CRDT, con un almacén clave-valor replicado que se ve funcionar.

**Ver en línea:** https://aaramirez.github.io/sistemas-distribuidos/
